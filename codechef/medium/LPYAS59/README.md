## Problem

Write a program to check whether a number given as user input is positive, negative, or zero.

### Sample 1:
Input
Output

```
20
```

```
Positive
```

### Sample 2:
Input
Output

```
0
```

```
Zero
```

### Sample 3:
Input
Output

```
-95
```

```
Negative
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-07-29T05:46:24.212Z  

```py
# cook your dish here
N=int(input())
if N>0:
    print("Postive")
elif N==0:
    print("Zero")
else:
    print("Negative")
```
